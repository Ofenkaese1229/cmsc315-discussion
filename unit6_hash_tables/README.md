3. Explain how hash tables behave, what collisions are, and how hash tables can improve efficiency.

A hash table stores data using key-value pairs and uses a hash function to help determine
where data is stored. A collision can occur when two different keys result in
the same hash location. Hash tables have ways to handle these collisions so the 
data can still be stored and accessed. This makes dictionaries useful because they
can provide fast lookups, insertions, and deletions, which is important for applications
that need to access information quickly.
